# SmartHouse 3D

Aplicação web interativa em tela cheia (PWA) para controle visual e espacial de um apartamento inteligente em rede local, usando um único contexto WebGL com planta 3D procedural reativa.

## Status Atual

- **Fase:** Blueprint aprovado — tarefas da V1 definidas em `docs/tasks/` (pronto para iniciar implementação).
- **Escopo V1:** Execução local no computador em modo simulador (`MockIoTProvider`), com abstração pronta para futura migração para **Raspberry Pi 4 / Orange Pi 5** + **Home Assistant**.
